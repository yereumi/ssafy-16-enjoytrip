# ssafy-16-enjoytrip

# 개요

> 공공데이터를 활용한 EnjoyTrip 서비스

공공데이터 포털의 전국 관광지 정보 표준 데이터와 Java, STS, Jackson 라이브러리를 활용해 만든 서비스입니다.

# 기능
